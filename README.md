# hello-oss-project

Một chương trình C nhỏ in ra dòng chữ "Hello Open Source", dùng làm dự án

mẫu để thực hành viết tài liệu và chọn giấy phép cho phần mềm mã nguồn mở.

## Mục tiêu

- Làm quen với cách tổ chức một repository mã nguồn mở trên GitHub.

- Thực hành viết README, CONTRIBUTING và chọn LICENSE.

- Hiểu vai trò của tài liệu và giấy phép trong dự án OSS.

## Yêu cầu

- Trình biên dịch GCC (hoặc Clang)

- Git

## Hướng dẫn build và chạy

```bash

gcc main.c -o hello

./hello

```

Trên Windows dùng `.\hello.exe` để chạy.

Kết quả mong đợi:

```

Hello Open Source

```
